# PC Check

Windows PC 사용시간을 자동으로 기록하고 메일로 알려주는 데스크톱 앱입니다.

## 주요 기능

- 오늘 및 최근 7일 실제 사용시간
- 활성 프로그램별 사용시간
- 자리 비움 자동 제외
- Windows 로그인 시 강제 자동 실행
- 부모 비밀번호로 종료·일시정지·삭제·제거 보호
- 잘못된 비밀번호와 제거 시도 기록
- 알림 영역 상주

부모 비밀번호는 PBKDF2 해시로만 저장되며 원래 비밀번호는 저장하지 않습니다. 키 입력, 채팅 내용, 비밀번호, 웹사이트 주소는 수집하지 않습니다.

## 설치파일

GitHub Actions의 `Windows Setup Build` 실행 결과에서 `PC-Check-Setup` 아티팩트를 내려받아 압축을 풀고 `PC-Check-Setup.exe`를 실행합니다.
